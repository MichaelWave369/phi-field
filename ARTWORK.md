# Artwork notice

The original cinematic background files and animated energy halo already in the repository root were supplied by the project owner. The image files are **not covered by the project's MIT license for source code**. Their reuse and publication remain subject to the owner's rights and distribution decisions.

Production uses only these existing originals:

- `phi-field-desktop-ui-ready.webp`: optimized desktop background.
- `phi-field-mobile-full-world.webp`: mobile panorama.
- `phi-field-animated-halo.svg`: transparent decorative ring overlay.

The source/master and alternate art remain in the repository for editing and reference, but the GitHub Actions packaging script excludes them from the Netlify upload bundle. No duplicate binary files are committed by this website integration.

The scenery is still artwork. CSS introduces ambient light and drift, not actual independent animation of the painted dragon, aircraft, or waterfalls.
